# Asynchronous E-Commerce Market Intelligence Engine

I created this web scraper using Python, Playwright and BeautifulSoup to deal with a common problem in commercial data analysis: collecting data from e-commerce sites that have a lot of pages. The engine moves through catalog structures collects detailed product information and turns it into finished business spreadsheets.

## Key Architectural Features

The script works through three parts: browser automation, text parsing and spreadsheet formatting.

### Asynchronous Browser Automation

than using regular HTTP clients that don't work well with dynamic websites the script starts a headless browser session with Playwright. It uses native async loops to keep track of navigation states loading pagination links as needed and waiting for the network to be completely idle to stop requests from being lost or timing out.

### Data Cleaning and Normalization

After BeautifulSoup gets the HTML nodes the script does clean data transformations before saving the data:

* Title Extraction: Fixes text truncation by looking directly at the native title HTML attribute making sure product names are complete.

* Price Normalization: Removes currency symbols and spaces turning the values into floating-point numbers for math calculations.

* Rating Transformation: Changes text-based grading systems (like "Three" or "Five") into numbers (1-5) using a data dictionary that is set up in advance to save memory during runtime.

### Enterprise Excel Reporting

The data is put into a Pandas DataFrame. Sent out using OpenPyXL with specific layout changes for business use:

* Dynamic Column Widths: Stops text from being cut off by checking how long the text is in each column and adjusting the width automatically.

* Visual Typography Hierarchy: Makes header indexes stand out by using a 14pt Calibri font keeping the important data separate, from the raw information.
